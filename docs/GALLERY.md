## Live desktop demo

[![Live music preset recording](gallery/music-preset-live.jpg)](https://github.com/Ddrakkx/pigment/releases/download/v0.1.3-beta/Pigment-music-preset.mp4)

**[▶ Watch the 24-second video · 1080p / 60 fps](https://github.com/Ddrakkx/pigment/releases/download/v0.1.3-beta/Pigment-music-preset.mp4)**

An actual desktop recording showing `music` and `music off`, ordinary Windows
Terminal windows, the rotating ASCII logo, Matrix, CAVA, VIS, a terminal clock
and the lyrics player. Recorded by the project author on Windows.

Настоящая запись рабочего стола: запуск и выключение `music`, логотип, Matrix,
CAVA, VIS, часы и плеер со словами. Нажми на кадр, чтобы открыть видео.

Wallpaper shown: **Warrior's Tomb | Forest Sounds** in Wallpaper Engine.
The third-party wallpaper and music are demonstration content; their files are
not included in Pigment. The illustrated renderer previews below are separate
from this live recording.

## Text player

![Text player animation](text-player-en.gif)

The actual player painter with authored demo lyrics and simulated hover.
The wallpaper-based gallery composites are distributed under CC BY-SA 4.0.
Desktop/appearance scenes use Altai; CAVA/VIS use Milky Way; Matrix uses Scarlet
Tree; the dock scene uses Honeywave. See [authors and originals](../assets/wallpapers/CREDITS.md)
and the [license text](../assets/wallpapers/CC-BY-SA-4.0.txt).
The standalone player and installer previews use Pigment's original MIT artwork.

## More interfaces and layouts

![Globe search interface](gallery/globe-search.webp)

![Globe calculator](gallery/globe-calculator.webp)

These use the production globe screen and sphere painter with authored demo
results. They do not contain an index of the author's files or browsing history.
The calculator example is `128 * 32 = 4096`.

![Window overview preview](gallery/window-overview.webp)

The board controls, selection frame and hints use the production painter.
The three thumbnail images are staged previews: this is not a capture of native
live DWM thumbnails. They contain the demo library, terminal and Quiet preview.

![Built-in wallpaper library](gallery/wallpaper-library.webp)

The actual wallpaper page rendered with the bundled collection and a demo selection.

![Quiet desktop preset](gallery/quiet-desktop.webp)

![Glass desktop preset](gallery/glass-desktop.webp)

The actual preset preview widget. Its sample terminal and dock are illustrative;
these two images are not full desktop captures. Quiet uses Shell; Glass uses Scarlet Tree.

![Terminal on Shell](gallery/terminal-shell.webp)

Another frame from the actual rotating ASCII generator, placed in a staged
terminal scene with demo system information.

![Music settings](gallery/music-settings.webp)

The actual settings page with an authored demo track and original demo lyrics.

New wallpaper-based examples use Milky Way (globe and board), Shell (Quiet and
terminal), Scarlet Tree (Glass), or the five bundled library thumbnails. They
are distributed under CC BY-SA 4.0; attribution and original files are linked
in [wallpaper credits](../assets/wallpapers/CREDITS.md).
