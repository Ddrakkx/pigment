## Terminal + desktop

![Terminal and desktop renderer preview](gallery/desktop-terminal.png)

A wallpaper-colored terminal beside the calendar and clock. The ASCII logo
comes from Pigment's actual 3D frame generator; system fields are demo content.
The desktop composition and terminal frame are staged previews.

## CAVA / VIS

![CAVA with a demo audio signal](gallery/cava.png)

![VIS with a demo audio signal](gallery/vis.png)

Output captured from the production C# spectrum painter, using a deterministic
demo signal, then arranged into a terminal-style preview. This is not a live audio recording.

## Matrix mood

![Matrix styling scene](gallery/matrix.png)

An illustrative styling scene with character rain. This is not a live cmatrix capture.

## Wave dock

![Wave dock production painter](gallery/dock.png)

The real dock painter with a staged set of icons and a simulated hover position.

## Appearance page

## Text player

![Text player animation](text-player-en.gif)

The actual player painter with authored demo lyrics and simulated hover.
The wallpaper-based gallery composites are distributed under CC BY-SA 4.0.
Desktop/appearance scenes use Altai; CAVA/VIS use Milky Way; Matrix uses Scarlet
Tree; the dock scene uses Honeywave. See [authors and originals](../assets/wallpapers/CREDITS.md)
and the [license text](../assets/wallpapers/CC-BY-SA-4.0.txt).
The standalone player and installer previews use Pigment's original MIT artwork.
